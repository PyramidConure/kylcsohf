# Creator Control Center 2.0

Локальное приложение для Windows 10/11 на Python 3.12+, PySide6 и SQLite. Интерфейс на русском языке. Данные хранятся на компьютере, а токены, секреты OAuth, адреса сессий загрузки и настройки прокси — в Windows Credential Manager.

## Установка и первый запуск

1. Установите [64-битный Python 3.12 или новее](https://www.python.org/downloads/windows/). Включите установку Python Launcher или добавление Python в PATH.
2. Откройте папку проекта и запустите **install.cmd**. Он создаст локальную папку .venv и установит зависимости. Если Python установлен без PATH, передайте полный путь к python.exe аргументом.
3. Запустите **start.cmd**. Первый запуск создаёт базу data\creator.sqlite3. По умолчанию включён тестовый режим.
4. Для импорта и обработки видео нужны ffmpeg.exe и ffprobe.exe. Программа использует папку из настроек, затем локальную сборку в `.tools/ffmpeg/bin` или PATH. Если FFmpeg отсутствует, скачайте [сборку Essentials для Windows](https://www.gyan.dev/ffmpeg/builds/) и укажите её папку bin в настройках.
5. Для эмуляторов установите LDPlayer и укажите его папку с ldconsole.exe или dnconsole.exe и adb.exe. Для диагностики и снимков включите локальный ADB в нужном экземпляре. В разделе «Эмуляторы» нажмите «Обнаружить». [Справка LDPlayer](https://ru.ldplayer.net/support/rukovodstvo-po-komandnoy-stroke-ldconsole.html)

На этом компьютере рабочая папка расположена на SSD в `E:\Creator Control Center`.
Окна импорта и сохранения по умолчанию открывают папки media, backups и screenshots внутри data рядом с базой.

Эквивалент команд для PowerShell.

~~~powershell
.\install.cmd
.\start.cmd
# Указать другой каталог базы
.\start.cmd --data-dir "E:\CreatorData"
~~~

## Работа в приложении

- **Обзор и задачи.** Обзор показывает ближайшие и просроченные шаги. Раздел «Задачи» добавляет разовые задачи с датой и, при необходимости, аккаунтом. Пока окно открыто, строка состояния периодически напоминает о наступивших сроках.
- **Аккаунты.** Добавьте собственный Instagram-аккаунт или YouTube-канал. Заполните тематику, язык, страну и часовой пояс аудитории. Для США используются код US и язык English. Укажите идеи, референсы и ответственного. Для ручной работы в LDPlayer возьмите индекс из раздела «Эмуляторы».
- **Прогрев Instagram.** Карточка создаёт календарь. Для 14-дневного плана настройка занимает дни 1–3, исследование 4–7, подготовка контента 8–14. Задачи публикации и анализа начинаются с 15-го дня. При изменении длительности этапы масштабируются, а отметки сохраняются. Карточки этапов фильтруют задачи, а кнопка «Сегодня» открывает задачи на текущую дату. Статус можно выбрать вручную. Календарь помогает подготовке и не ограничивает право отправки при готовности.
- **Видео.** Выберите несколько файлов. Каталог ссылается на них по исходным путям, FFprobe проверяет дорожки, а SHA-256 выявляет копии. Если переместили файл, выберите его через «Указать новый путь…». Программа сверит SHA-256 и сохранит связи с очередью. Предпросмотр открывается в системном проигрывателе. «Подготовить MP4 9:16» создаёт отдельный файл 1080 × 1920 с полями при необходимости, H.264, 30 кадр/с и AAC 48 кГц при наличии звука.
- **Публикации.** Добавьте черновик с аккаунтом, видео, описанием, темой и временем в часовом поясе Windows. Сохраните изменения перед проверкой или отправкой. В тестовом режиме «Проверить черновик» проверяет файл и параметры локально. В рабочем режиме дождитесь срока и подтвердите отправку. Если YouTube прервал передачу, «Продолжить отправку» использует сохранённую сессию и сверяет полученный объём. Если Meta обрабатывает файл, вернитесь к записи и продолжите после готовности. При неопределённом результате финальной команды Meta нажмите «Проверить результат» и сверьтесь с Instagram. Если контейнер уже опубликован, а ID медиа не вернулся, возьмите его из своего списка медиа API и используйте «Связать ID публикации».
- **Аналитика.** Выберите аккаунт, период 7 или 30 дней и нажмите «Собрать через API». Отчёт охватывает завершённые дни. До нового сбора программа показывает последний сохранённый отчёт с его исходными датами. Вкладки публикаций и тем используют накопительные показатели связанных публикаций. Разница по подписчикам Instagram доступна при наличии снимков на обе даты. Пустые метрики помечаются как недоступные. Платформы могут публиковать данные с задержкой.
- **Эмуляторы.** Диагностика показывает ответ ADB, загрузку Android, наличие Instagram и выборочное использование CPU/RAM процессов LDPlayer. Если ADB зависает, операция завершится по тайм-ауту. PNG сохраняется по выбранному пути. Для снимка откройте тестовый экран в нужном экземпляре.
- **Безопасность подключения.** Проверка по запросу оценивает доступность API и задержку трёх запросов. Опциональная проверка через ipify.org сравнивает IP только в памяти текущего сеанса. Прокси используется только по явному выбору в диагностике. Проверка сети не меняет календарь.
- **ИИ-чат.** Раздел находится сразу после «Обзора». Беседы и поиск находятся слева, сообщения по центру, поле ввода внизу. Панель бесед можно свернуть кнопкой «Беседы». Enter отправляет сообщение, Shift+Enter добавляет строку. Заготовки помогают начать сценарий или контент-план. Выбор аккаунта для новой беседы добавляет его тему, аудиторию и идеи к отправляемому контексту. История сохраняется в локальной базе. Смена модели сохраняет предыдущие сообщения и подписи моделей у ответов. Кнопка ↻ обновляет список доступных GPT-моделей через OpenAI, ранее выбранные модели остаются в списке. Для переименования беседы используйте F2 или контекстное меню.

В верхней панели отображаются дата и часы с секундами. Переключатель предлагает Москву, Питер, Иркутск и Улан-Удэ. Выбор города сохраняется между запусками.

Черновики ИИ-чата автоматически сохраняются в локальной базе, отдельно для каждой беседы. При перезапуске восстанавливаются последняя беседа, её черновик и выбранный контекст новой беседы. Поиск просматривает названия, аккаунты и текст сообщений. «Экспорт» сохраняет беседу с подписями моделей в новый Markdown-файл, по умолчанию в `data/chats`. Ctrl+N открывает новую беседу, Ctrl+F переводит фокус в поиск. Для неудачного сообщения кнопка «В поле ввода» позволяет сначала отредактировать текст и затем отправить его вручную.

Кнопка «ИИ-план» в аккаунтах и разделе подготовки открывает беседу выбранного аккаунта. Кнопка «Следующий шаг» готовит вопрос для отправки. В контекст входят фактически завершённые задачи и ближайшие открытые шаги. Ответ чата сам по себе не отмечает задачи и не публикует материалы.

В [примере подготовки двух аккаунтов](examples/ai-model/README.md) находятся исходники оформления, английские тексты, контент-план, сценарии и сборщик двух локальных демороликов. Для оригинальных тестовых карточек материалы и результаты проверки сохраняются в `data/plans/nova-starter-20261105`, видео — в `data/media/nova-starter-20261105`. Графические деморолики требуют просмотра владельцем перед использованием. Фотореалистичный образ персонажа в этом пакете не создаётся.

## Подключение ИИ-чата

Откройте «Настройки → ИИ-чат», введите OpenAI API-ключ и сохраните настройки. По умолчанию выбрана модель gpt-5.4-mini, имя модели и лимит ответа можно изменить. Запросы используют баланс вашего API-проекта. Ключ хранится в Windows Credential Manager, сообщения — в SQLite рядом с остальными данными. В запросах используется Responses API с параметром store=false, история передаётся из локальной базы. [Документация OpenAI](https://developers.openai.com/api/docs/guides/conversation-state)

Сохранённый выбор модели остаётся в истории. Возможность получить новый ответ зависит от её доступности и поддержки Responses API в вашем проекте OpenAI. Отключённая OpenAI модель не становится доступной за счёт сохранения её имени. [Каталог моделей OpenAI](https://developers.openai.com/api/docs/models)

## Подключение официальных API

### YouTube

В своём проекте Google Cloud включите YouTube Data API v3 и YouTube Analytics API. Настройте экран согласия, добавьте свой аккаунт в тестовые пользователи, если приложение работает в тестовом режиме Google, и создайте OAuth-клиент типа **Desktop app**. Введите Client ID и Client Secret в «Настройки → OAuth». Сохраните карточку канала и нажмите «Подключить OAuth». Браузер вернёт код в приложение через loopback на 127.0.0.1 и случайном порту с PKCE. Перед подтверждением публикации проверьте имя канала и выбранную видимость. «Проверить результат» показывает фактическую видимость и статус обработки. [OAuth для desktop](https://developers.google.com/youtube/reporting/guides/authorization/installed-apps) · [YouTube Data API](https://developers.google.com/youtube/data/reference/rest/v3/videos/insert) · [YouTube Analytics](https://developers.google.com/youtube/analytics/reference/reports/query)

### Instagram

Подготовьте собственное приложение Meta с **Instagram API with Instagram Login** и собственный профессиональный Instagram-аккаунт Business или Creator. Добавьте аккаунт к приложению и получите разрешения instagram_business_basic, instagram_business_content_publish и instagram_business_manage_insights для нужных действий. Укажите Instagram App ID, App Secret, версию Graph API из настроек вашего приложения и зарегистрированный HTTPS redirect URI. Используйте страницу на своём домене, где вы можете скопировать полный адрес после согласия. Страница должна сохранять параметры callback в адресной строке и исключать их передачу третьим лицам. Скопируйте адрес из браузера в скрытое поле приложения и завершите OAuth. [Instagram Login](https://developers.facebook.com/docs/instagram-platform/instagram-api-with-instagram-login/business-login) · [Официальная коллекция Meta](https://www.postman.com/meta/instagram/collection/6yqw8pt/instagram-api)

Для публикации Reels укажите доступную серверам Meta прямую HTTPS-ссылку на этот же видеофайл на своём хостинге. Ссылка должна быть публичной без cookies и токенов в адресе на время обработки контейнера. Приложение проверяет локальную копию и передаёт адрес Meta. Проверка формата и ограничений на стороне платформы остаётся окончательной. [Требования к Reels](https://www.postman.com/meta/instagram/folder/830j7my/reels-publishing)

## Резервное копирование и сбои

В «Настройки → Программа» выберите «Резервная копия SQLite» и новый файл. Копия создаётся через SQLite Backup API с проверкой целостности. Видео остаются по исходным путям. Секреты хранятся в профиле Windows отдельно от базы.

Для восстановления укажите новый рабочий каталог и путь к резервной копии. Приложение откроет восстановленную базу в тестовом режиме и поставит незавершённые отправки и черновики на сверку. Переподключите аккаунты и проверьте соответствующие записи на платформе. Найденный ролик можно связать по ID. Черновик без следов отправки можно вернуть в очередь после ручной сверки. Записи с признаками начатой отправки остаются на сверке до подтверждения результата.

~~~powershell
.\start.cmd --data-dir "E:\CreatorData-restored" --restore "E:\Backups\ccc.sqlite3"
~~~

Если результат отправки неизвестен, проверьте запись через приложение и в YouTube Studio или Instagram. Запись с сохранённым результатом или начатой финальной отправкой Meta блокирует повторный запрос. Один файл в очереди связывается с одним аккаунтом только один раз. Локальный журнал в очереди хранит этапы отправки и коды отказов, а data\activity.log записывает фоновые операции и их результаты без токенов, URL авторизации и IP.

## Проверка разработки

Исходный код связан с репозиторием [PyramidConure/kylcsohf](https://github.com/PyramidConure/kylcsohf).
Workflow Windows checks проверяет зависимости, интерфейс, базу и видео на Windows при отправке в main и при pull request.
На странице Actions репозитория можно открыть результат каждой проверки.

~~~powershell
.\.venv\Scripts\python.exe -m unittest discover -v
# Проверить внешнюю установку FFmpeg и FFprobe
$env:CCC_FFMPEG_DIR = "E:\Tools\ffmpeg\bin"
.\.venv\Scripts\python.exe -m unittest discover -v
~~~

Тест Windows Credential Manager создаёт временную запись с фиктивным значением и удаляет её. Ему требуется обычный сеанс Windows. API-тесты используют подменные ответы, а запуск настоящих публикаций требует ваших зарегистрированных приложений и явного подтверждения в интерфейсе.
