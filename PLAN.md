# План Creator Control Center 2.0

## Аудит вложений

Рабочая папка до начала работы была пуста. Восемь исходных вложений прочитаны отдельно. «ИНСТРУКЦИЯ.txt» описывает 1.0. Полное ТЗ 2.0 получено в уточнении пользователя.

| Материал | Существующая функция и ограничения | Решение для 2.0 |
| --- | --- | --- |
| BAT 1, BAT 2, skipper.py | Открытие Shorts, случайные свайпы, UI-дампы, пропуск рекламы. Распознавание зависит от языка и координат. Список ADB охватывает любые подключённые Android-устройства. | Устройство определяется по индексу LDPlayer. Действия только для диагностики и ручного запуска Instagram. |
| BAT 3, BAT 4 | Остановка магазина и загрузок, очистка кэшей, смена сетевой политики. Отчёт возможен даже при ошибке команды. | Диагностика без массового изменения настроек Android. |
| BAT 5, settings.bat | Путь к LDPlayer, штатное закрытие через ldconsole. | Настраиваемый путь, адресные команды, ограничение времени, проверка вывода. |
| ИНСТРУКЦИЯ.txt | Установка и эксплуатация версии 1.0. | Новая инструкция Windows для Python 3.12+ и PySide6. |

## Этапы и проверки

1. Создать пакет приложения, SQLite и оболочку PySide6. Проверить создание базы, резервную копию, запуск интерфейса.
2. Сделать встроенный редактор аккаунтов, план Instagram, контроль сроков и ручные задачи. Проверить шаблон на 14 дней, изменение длительности, статус и сохранение выполненных шагов.
3. Добавить LDPlayer, диагностику подключения, каталог видео и FFmpeg. Проверить формат ответов консоли, команды и обработку собственных видео.
4. Реализовать OAuth, хранилище Windows Credential Manager, очередь публикаций, журнал и аналитику. Проверить контракты официальных API подменными ответами, блокировку повторной отправки после сбоя и тестовый режим.
5. Выполнить тесты, пройти интерфейс по основным сценариям и описать установку и восстановление. Живая приёмка публикаций требует зарегистрированных приложений Google и Meta, прав на собственные аккаунты и явной отправки из интерфейса.

## Структура

- creator_control/db.py — SQLite, аккаунты, задачи, очередь и снимки метрик.
- creator_control/planning.py — шаблон Instagram и правила прогресса.
- creator_control/tools.py — процессы, LDPlayer, FFmpeg и сеть.
- creator_control/credentials.py — Windows Credential Manager.
- creator_control/platforms.py — OAuth и клиенты официальных API.
- creator_control/publishing.py — координация очереди, отправка и сверка.
- creator_control/ui/ — окно, страницы, встроенные редакторы и фоновые операции.
- tests/ — проверки доменной логики, адаптеров и интерфейса.
